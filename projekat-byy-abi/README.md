# Džemat Vreoca - Zvanična Web Platforma

## Vizija
Moderna, brza i pristupačna web platforma za Džemat Vreoca (Ilidža, Sarajevo), pod okriljem Islamske zajednice u Bosni i Hercegovini. Platforma omogućava džematlijama uvid u tačna namaska vremena (uživo vaktija.ba API), online prijavu djece u mekteb, direktan kontakt i postavljanje pitanja imamu, pregled hutbi, aktivnosti i podršku džematu kroz donacije.

## Glavni Cilj
Digitalizacija i olakšavanje komunikacije između džemata, imama, roditelja polaznika mekteba i džematlija u domovini i dijaspori.
