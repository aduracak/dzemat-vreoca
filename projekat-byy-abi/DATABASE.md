# DATABASE - Šema baze podataka (Supabase PostgreSQL)

## Tabele

### 1. `mekteb_prijave`
- `id` (BIGINT PRIMARY KEY)
- `parent_name` (TEXT)
- `child_name` (TEXT)
- `birth_year` (INTEGER)
- `phone` (TEXT)
- `email` (TEXT)
- `group_level` (TEXT)
- `status` (TEXT: 'na_cekanju', 'upisano', 'arhivirano')
- `notes` (TEXT)
- `created_at` (TIMESTAMP)

### 2. `pitanja_imamu`
- `id` (BIGINT PRIMARY KEY)
- `sender_name` (TEXT)
- `sender_contact` (TEXT)
- `question` (TEXT)
- `answer` (TEXT)
- `is_published` (BOOLEAN)
- `category` (TEXT)
- `answered_at` (TIMESTAMP)
- `created_at` (TIMESTAMP)

### 3. `hutbe`
- `id` (BIGINT PRIMARY KEY)
- `title` (TEXT)
- `date_str` (TEXT)
- `category` (TEXT)
- `summary` (TEXT)
- `content` (TEXT)
- `author` (TEXT)
- `created_at` (TIMESTAMP)

### 4. `aktivnosti` (NOVO)
- `id` (BIGINT PRIMARY KEY)
- `title` (TEXT NOT NULL)
- `date_str` (TEXT NOT NULL)
- `time_str` (TEXT)
- `location` (TEXT DEFAULT 'Džamija Vreoca')
- `category` (TEXT: 'Edukacija', 'Humanitarno', 'Omladina', 'Džemat')
- `summary` (TEXT NOT NULL)
- `description` (TEXT NOT NULL)
- `is_active` (BOOLEAN DEFAULT TRUE)
- `created_at` (TIMESTAMP)

### 5. `newsletter_pretplatnici` (NOVO)
- `id` (BIGINT PRIMARY KEY)
- `email` (TEXT UNIQUE NOT NULL)
- `name` (TEXT)
- `is_active` (BOOLEAN DEFAULT TRUE)
- `created_at` (TIMESTAMP)
